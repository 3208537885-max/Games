# 水课梦魇 · Dream Campus

> 上课，睡着。醒来，把整个梦打通。

原创校园主题单人房间式 Roguelite 网页游戏。大学生在水课上睡着，穿过教学楼、食堂/宿舍和行政楼，击败「梦境校长 · 学分之主」，回到现实。这里有喷水的水课课本、会追人的快递、可以部署的校园网，以及地质专业彩蛋。

## 马上开始

**最快：双击 `standalone.html`。** 这是完整单文件离线版，不是试玩截图，所有样式、脚本和原创 SVG 都已内嵌。也可以双击根目录的 `index.html`，但不要把它单独移走。

Windows 也可双击 `启动游戏.bat`，通过本地静态服务器打开。电脑需要已有 Python；游戏本身不需要 Python。

```bash
# 可选：用本地服务器模拟上线后的环境
python tools/serve.py --open
# 默认 http://127.0.0.1:8787；端口被占用时可以 --port 8788
```

不需要安装 npm 包、不需要后端、不需要账号、不需要 API Key、不请求远程图片、字体或音乐。已结束的记录、成长和房间检查点保存在浏览器中；存储受限时仍可玩，但持久保存不可保证。

## 这一版有什么

| 内容 | 已实现 |
|---|---|
| 完整流程 | 序章 → 3 章探索与战斗 → 3 位首领 → 终局特效 → 现实世界尾声 → 奖励 → 再次开局 |
| 地图 | 每章 11 / 12 / 13 个房间，总计 36 个房间节点；固定可达主路、随机走向和支路、随机室内障碍 |
| 武器 | 48 件；6 个品质档；13 类攻击行为；每件可升级至 +3 |
| 构筑 | 28 件不重复遗物、8 组双武器标签羁绊、2 个武器槽 |
| 角色与强度 | 3 名角色、3 档难度；局外 3 类有上限的成长 |
| 敌人 | 12 类普通敌人，加分裂子怪；3 位有三阶段招式的首领 |
| 非战斗内容 | 宝箱、商店、升级、休息、8 类奇遇；精英挑战可以不去 |
| 操作 | 键鼠、触屏双摇杆、自动瞄准/自动射击选项、暂停与切出自动暂停 |
| 记录 | 房间检查点、种子复玩、本地战绩、图鉴、存档 JSON 导入/导出 |
| 通关奖励 | 「毕业证发射器」解锁、额外灵感、可生成的 SVG 毕业纪念证书 |
| 美术与声音 | 原创矢量封面、角色、敌人、物品、场景、粒子、合成器音乐与音效 |

随机的是地图连接、房间布局、敌人组合和可控的物品奖励。不是无限关卡，也不是任意形状的开放世界。同一种子保证地图、布局和关键奖励生成一致；不同走位、消灭顺序、难度、解锁状态与重进检查点会改变实际战斗。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标瞄准 + 按住左键 | 连续攻击 |
| 空格 | 闪避，短暂无敌，不能穿墙 |
| E | 交互、拾取、打开商店、进入传送阵 |
| 1 / 2 / 鼠标滚轮 | 换武器 |
| Q | 「拒绝内卷」：清除敌弹并伤害附近敌人 |
| R | 喝水回专注，短暂停火，但仍能移动 |
| F | 切换自动瞄准射击 |
| M / Tab | 地图 / 背包 |
| Esc | 暂停 / 关闭普通面板 |

第一次可以用「正常修读」体验，碰到困难再切「轻松旁听」。不会自动射击时请按住鼠标左键；选择近战武器时要靠近敌人。炮台、环绕物部署后，换另一把武器仍会继续工作。清房后走进发光的门，不需要按 E；章节传送阵才需要靠近按 E。

手机横屏视野更合适。竖屏也有独立的摇杆与技能区，但场景会更小。本次触屏验证是 Chromium 模拟输入，不代表已覆盖所有真机浏览器。

## 给 Codex：只做接入，不要重写

先看 **`CODEX_HANDOFF.md`**。`dist/` 已经是可以直接托管的静态目录。

建议的最小工作量：把 `dist/` 的内容复制到已有项目的 `public/games/dream-campus/`，再加一个入口链接或 iframe。不要迁移现有框架，不要覆盖原项目的 `package.json`、首页、路由配置或部署配置。

`integrations/` 提供 React / Next.js、Vue 和普通 HTML 容器参考。没有要求宿主必须使用这些框架。

## 修改与重建

增删武器、改名字、调整强弱：优先改 `src/data.js`。改美术：`src/art.js`、`src/renderer.js` 或 `assets/key-art.svg`。改网页主题：`styles.css`。新攻击行为和宿主事件见 `docs/ARCHITECTURE.md`。

```bash
node tests/core.test.cjs     # 无依赖核心回归
node tests/balance.cjs       # 48 件武器的真实引擎伤害实验
python tools/build.py        # 重新生成 standalone.html 和 dist/
```

浏览器 QA 另外需要 Python Playwright 和可用的 Chromium；玩家和部署环境不需要安装这些 QA 依赖。已经随包提供本次测试结果。

**修改源文件后必须重建，不能只改 `dist/` 或只改单文件版。** 工具不会自动改动宿主项目。

## 边界

这是有头有尾、可运行的首版单人游戏，不是假静态演示；也不是经过长期运营与大量玩家测试的商业成品。自动测试检查的是流程和机制，不能证明所有武器组合的强度已经最优。没有联网联机、云存档、服务器排行、付费、账号或反作弊。当前没有在你的个人网站上实际部署，因为本包没有包含你的宿主项目或托管权限。

角色、校园、校长和情节均为虚构。毕业纪念证书仅为游戏通关纪念，不代表真实学位或学历。代码及本包自绘美术采用 MIT 许可证；未附带任何字体文件。
