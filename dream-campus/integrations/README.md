# 宿主容器参考

这些文件不是游戏运行依赖，也没有替你放入任何个人项目。最少工作的接入仍然是复制 `dist/` 并加一个链接。

`ReactGame.tsx` 可作为 React/Next.js 的薄 iframe 容器；`VueGame.vue` 用于 Vue；`embed.html` 在本包内直接预览普通 iframe 嵌入。组件需要宿主已经具有相应框架；不要为了使用示例给静态站安装 React/Vue。

组件的默认路径需要适配你已有项目的 basePath。可选结算回调只供界面展示，不是可信的排行榜数据。跨窗口消息必须检查来源。当前没有宿主项目，因此 React/Vue 模板未经过你的宿主构建与路由验证。
