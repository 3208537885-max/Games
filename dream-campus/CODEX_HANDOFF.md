# Codex 首读：只接入，别重造游戏

## 目标

把这份**已经可运行的静态游戏**挂到用户现有个人项目。减少改动、减少阅读量、减少 token 消耗；本任务不是让你重写游戏。

## 先读这几个文件就够了

1. 本文件。
2. 宿主项目自己的 `package.json`、路由/页面结构、已有静态资源目录。只读必要范围。
3. 本包 `config.js`。需要容器时再看 `integrations/ReactGame.tsx` 或 `VueGame.vue`。

接入阶段不要全文扫描 `src/game.js`、测试截图和所有设计文档。不要重新调研游戏框架。

## 最小实施路径

**首选直接链接：** 把本包 `dist/` 的内容复制到宿主静态目录 `public/games/dream-campus/`，在个人项目现有作品列表加一张卡片或链接，指向 `/games/dream-campus/index.html`。直接链接可让游戏占满页面，工作量最小。

**需要站内页面时：** 新增一个很薄的游戏页面，里面放 iframe：

```html
<iframe
  src="/games/dream-campus/index.html"
  title="水课梦魇：校园梦境冒险"
  style="width:100%;height:calc(100dvh - 72px);min-height:420px;border:0;display:block;"
  allow="autoplay"
></iframe>
```

路径仅是建议：如果宿主部署在子路径，必须沿用宿主的 basePath / public base 机制，不要硬编码到域名根。先确认目录中没有同名项目；存在则停下说明冲突，不要直接覆盖用户旧文件。

### 不准为接入而做的事情

- 不更换 React / Vue / Next.js / Vite 等现有架构。
- 不用 Phaser、Unity、Three.js 重写当前引擎。
- 不覆盖原项目的 `package.json`、首页、路由总配置、部署配置、全局 CSS。
- 不把游戏的 `styles.css` 直接注入宿主全局；iframe 或独立页面可以隔离样式。
- 不安装游戏运行依赖：本项目运行依赖数为 0。
- 不新增后端、数据库、登录、API Key、付费服务、分析埋点或外部资源请求。
- 不擅自修改现有武器数值、关卡、剧情、奖励与存档机制；新增内容应先写入 `src/data.js` 并补测试。
- 不把 `tests/`、设计文档和根目录示例服务器作为必须的生产文件部署。
- 没有真实发布权限时不要声称已上线；只报告本地接入与测试结果。

## 验收清单

- 原项目原有页面仍可访问，原有构建命令正常。
- 入口能打开真实游戏，而非只显示封面。
- 游戏子路径中的 `config.js`、`src/*.js`、`styles.css` 和 SVG 全部返回正确资源，不是 SPA 回退的宿主 HTML。
- 可以开局、跳过序章、移动、瞄准攻击、换武器、暂停、开地图。
- 宿主路由退出/隐藏时不会继续收到游戏操作；iframe 随页面销毁即可。
- 刷新可回到房间检查点（**不是战斗中每一帧原地续玩**）。
- 正式入口不携带 `?debug=1`，`config.js` 中 `debug` 保持 false。
- 结束时只报告修改了哪些宿主文件、访问路径、实际测试了什么、是否真实部署成功。

满足后停止，不追加“顺便重构”。

## 可选功能，不是本次必须工作

- 改标题/存档前缀：改 `config.js`。
- 接入本地结算 UI：同源 iframe 可使用 `DreamCampus.on('run:end', callback)`；跨窗口事件必须校验 `source` 和精确 `origin`。
- `integrations/ReactGame.tsx` 已演示同源事件连接与清理。若没有事件需求，普通链接最省事。
- 改玩法再读 `docs/ARCHITECTURE.md`，不要在纯接入任务中先改玩法。
