# 首版边界与后续优先级

- 这是独立、完整的单人游戏首版，不是联机服务。没有账号、云存档、服务器排行榜、支付或反作弊。
- 本次自动验证覆盖 Chromium、DOM、Canvas、键盘、模拟触屏、核心模拟和结局。没有完成真实 iOS Safari、Android 机型矩阵、低端设备长时间温升或全部屏幕阅读器测试。
- 持久化以房间边界为准，不保存战斗中间的弹丸与怪物逐帧状态。回到菜单再续玩可能重打当前房间。关键选择、支出与已清房间会在确认时保存。
- 浏览器 QA 环境限制直接导航；因此用 Playwright `set_content` 加载相同的离线单文件字节，存档交互采用注明的内存 Web Storage 替身，并另测存储不可用降级。原生磁盘持久化及正式站点导航仍需在实际宿主上验收。
- 地图有明确的房间图结构与室内障碍随机，不是任意地形、无限开放世界或无限楼层。
- 30 秒木桩伤害实验不是玩家通关率。不能据此断言任意搭配都完全均衡。需要真实玩家反馈后再调精英密度、弹速、Boss 容错和稀有物品体验。
- 启用辅助瞄准会优先瞄准最近可见敌人，不支持手柄和精细的目标锁定轮盘。
- 美术为原创程序矢量风格，不是大量逐帧手绘动画；没有语音配音。音乐为程序合成。
- `?debug=1` 提供开发检查工具。离线客户端本身可以改代码，因此仅隐藏调试入口不能形成反作弊。
- 单文件版与多文件版使用相同源代码生成。不能只改其中一份而期待另一份自动更新。
- 没有给宿主项目做真实代码修改或公开部署；接入示例不能替代宿主本地构建测试。

后续最有价值的事情是先请 3–5 位玩家各玩一次，记录最早卡住的位置、常用武器与死亡原因，再做小范围数值迭代；不是先更换引擎或增加付费云服务。
